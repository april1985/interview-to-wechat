# 访谈转公众号 · interview-to-wechat

一个面向 Codex 的编辑技能：从飞书妙记或访谈文字记录出发，完成脱敏、选题、文章改写、系列配图规划、头图和可复制的公众号 HTML。

它把一套经过实际编辑迭代的工作方法保存下来，让下一篇访谈不必重新交代流程。文章的主题和结构由每次访谈决定。

## 能做什么

- 读取完整发言，区分受访者原话、采访者表述和作者思考。
- 默认匿名处理，排除隐私和明确限于交流的内容。
- 提炼读者问题，组织正文，打磨摘要、标题、开头与结尾。
- 根据内容选择流程图、观点图或行动卡，控制同组视觉一致性。
- 生成可打开、可复制正文的 HTML，图片内嵌，无需外部图床。
- 定向修改内容和配图后，重新生成交付文件。

## 安装与使用

将仓库放入个人技能目录：

```bash
git clone https://github.com/april1985/interview-to-wechat.git ~/.codex/skills/interview-to-wechat
```

如果该路径已存在，先保留自己的修改，选择另一个目录检查新版本；不要直接覆盖已有技能。

在可以发现本地技能的 Codex 环境中调用：

```text
使用 $interview-to-wechat，把这个妙记链接整理成公众号文章。
<访谈链接>
```

可以增加具体要求，例如“保留实名”“控制在 2000 字”或“侧重产品经验”。若希望在某个工作区只发链接就启动，可在该工作区的 `AGENTS.md` 中约定：

```text
用户仅提供访谈妙记链接时，默认按 interview-to-wechat 技能制作公众号文章；
明确只阅读或只总结时，以当次要求为准。
```

## 环境与边界

这是供智能体执行的工作流，加上一个独立排版脚本，不是自动抓取、写稿和发布的一键后台服务。

- 读取私有妙记需要用户已有访问权限，以及当前环境可用的浏览器或连接器。仓库不提供登录凭据、抓取接口或绕过访问限制的方法。
- 图片实际生成需要环境具备相应图像工具。图像生成的可用性、配额和费用取决于使用环境；没有图像工具时，不能声称已交付图片。
- HTML 排版脚本仅依赖 Python 3 标准库。它不负责读取妙记、写作、生成图片或发布到公众号。
- 图片建议单独上传公众号；复制粘贴后的样式仍需在编辑器内检查。
- 发布到公众号或其他外部平台，需要用户另行授权。

## 独立使用排版脚本

示例全部为虚构内容：

```bash
python3 scripts/render_article.py examples/article.json
```

在 JSON 所在目录输出 `公众号文章.html` 和 `公众号文章.txt`。支持普通段落、大标题、小标题、引语、卡片、本地图片与注释。文本中的 `**重点**` 会显示为青绿强调，其余内容按普通文本转义。图片可使用相对 JSON 的本地 PNG/JPEG/WebP 路径。

完整字段与视觉规范见 [references/visual-style.md](references/visual-style.md)。
