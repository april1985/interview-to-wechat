# 默认视觉与 HTML

这是一套可调整的默认视觉方案；可根据作者偏好和文章主题修改。

## 正文

- 正文 16px，行高约 1.95，段后约 22px；手机左右留白约 23px。
- 青绿强调 `#155C58`；正文 `#333D42`。
- 大标题：浅橙编号、青绿文字、底部一道浅细线，明显上下留白。
- 小标题：18px、较轻字重、无编号，无重复解释副标题。
- 原话框：浅青绿底 `#EEF6F3`、青绿细左边，文字保持可编辑。
- 短摘要：用左上与右下转角箭头和留白包围几句导语。只参考文学杂志的构图，不复制其他媒体的署名、品牌或原创声明。

## 系列章节图

- 很浅的暖米色全幅底 `#FCFBF8`，薄荷绿卡片、青绿文字、细线图标、少量浅橙。
- 清新、轻盈，避免粗黑字、大色块和重边框，小屏文字须可读。
- 默认竖版约 4:5，可按内容改变。不为凑五步补无依据的步骤；有循环关系才画回程箭头。
- 用同一张已核对样板控制字形、字重、字号、图标线宽、卡片尺寸、圆角和留白。
- 图标表达具体动作。人机协作可用人形、双向箭头和芯片，避免与品牌标志相似。
- 不添加姓名、源链接、日期或底部来源小字。

## 结尾图与头图

结尾按内容选择复盘卡、问题卡或提醒卡，可用暖米色、深棕和宋体风格，与流程图区分。主标题说明用途，标题前可用浅橙短竖线；每组之间一道细分隔线即可，不叠加填写横线。

头图默认约 2.35:1 横版，围绕真实问题或具体隐喻；文案短而清楚，主元素留足裁切安全区。与正文配色协调，不强制用全文标题；头图单独交付。

## 内容 JSON 与 renderer

JSON 与素材放在同一篇文章目录，运行：

```bash
python3 scripts/render_article.py /path/to/article.json
```

输出同目录 `公众号文章.html`、`公众号文章.txt`。内容修改后重跑。

```json
{
  "title": "本次文章标题",
  "summary": "短摘要",
  "label": "访谈与实践",
  "blocks": [
    {"type": "p", "text": "作者开场。"},
    {"type": "part", "number": "01", "text": "本次主题"},
    {"type": "subhead", "text": "简短观点"},
    {"type": "p", "text": "正文，**这一段强调**。"},
    {"type": "quote", "text": "已核对归属的原话。"},
    {"type": "card", "title": "提醒", "items": ["第一条", "第二条"]},
    {"type": "image", "path": "章节配图.png", "alt": "可公开的图片说明"},
    {"type": "note", "text": "据访谈整理，受访者已匿名处理。"}
  ]
}
```

文本以 `**强调**` 标记重点，其余转义为普通文字；不在内容字段传入 HTML 或脚本。图片必须是已存在的 PNG/JPEG/WebP 本地素材，可用相对 JSON 目录的路径。头图不默认插入正文。alt 同样属于公开内容。
